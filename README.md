# Coastal Cleanup Data: Max Heap vs. Red-Black Tree

This C++ project compares a Max Heap and a Red-Black Tree for finding the 20 cleanup events with the highest item counts. It displays each event’s ID, location, date, and item count, along with the build and retrieval times for both structures.

## How to Run in CLion

1. Download whole repo as zip file.
2. Put everything into a folder, copy paste all data into the src folder, src contained the final draft of all code file.
3. Open **CLion**, choose **Open**, and select the src folder.
4. Wait for CLion to load the CMake project.
6. Click **Run**.

The project requires a C++17-compatible compiler.
